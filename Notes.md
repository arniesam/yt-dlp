**To install, type in the windows CMD window: winget install yt-dlp.yt-dlp** 
Here is how to run it step-by-step:

**Step 1: Open Command Prompt in Your Destination Folder**
By default, files download into whatever folder your terminal is currently open to.

Open File Explorer and go to the folder where you want your saved videos to go (e.g., your Downloads or Videos folder).

Click the address bar at the top of the window, type cmd, and press Enter.

A Command Prompt window will open already pointed at that specific folder.
